把平常的片刻，穿成喜欢的样子。

## 慢慢挑 认真看

- **先看最新一期**：首页直接展示最新发布的套装，再向下翻阅最近更新。每套都标注实际发布日期，历史档案不补写日期。
- **按自己的方式逛**：在“全部穿搭”中按风格、季节、模特或地区筛选，默认先看最新发布，也可切换风格漫游。
- **跟随模特探索**：在“模特”中查看她的已发布穿搭。历史图片未核对模特归属时，不会强行归给某位新模特。
- **找到心中那一套**：搜索名称、编号、单品、材质或情绪，试试“丝绒”“百褶裙”“惊喜”。
- **走近一个画面**：打开搭配，按镜头编号和名称选择 01—09，细看表情、动作与景别，再读单品与搭配思路。
- **顺着灵感继续逛**：详情中带链接的标签可搜索衣橱中的相关穿搭，浏览器返回可回到刚才那套。
- **走近每件单品**：在“单品”中探索新中式、街头、度假和每日穿搭的独立设计，查看完整形态、不同角度与细节，并回到原写真看穿着效果。单独收藏喜欢的单品；缺少原图依据的设计补充在说明中披露为设计推演。
- **全站主题**支持 12 种布局与视觉风格，包括 Editorial 留白叙事、Studio 大图图库、暗房样片、亚麻展室与夜间秀场。管理员可在工作台的“网站主题”中统一设置。前台打开或重新回到页面时读取当前主题，保留收藏和正在浏览的内容。
- **留住喜欢的**：点心形收藏，把 2—3 套加入对比，或点击“保存图片”。旧编号与收藏继续对应原来的搭配。

键盘也能帮忙：`/` 搜索，`←` `→` 切换详情中的搭配，`Esc` 关闭弹窗。

公开界面只展示“生动”版。历史“造型”图片和资料保留在项目归档中，不再放进公开构建与浏览入口。

## 收藏与照片

穿搭收藏与单品收藏分别留在当前浏览器中，不会上传你的收藏选择。换浏览器、打开地址或清理浏览数据后，收藏可能不会保留。

在线页面访问会在服务端通过离线 IP 库估算国家及中国省级归属，仅管理员可查看；不保存原始 IP，也不向第三方发送 IP 查询。归属地代表近似网络出口，可能受代理、运营商与数据库误差影响，不代表实际位置。匿名浏览器统计不等于实际人数，历史缺失地域不会补造。

打开「我的试穿」即可管理这台浏览器上的试穿照片和历史记录。拍摄或从相册选入的照片保存在本站的浏览器数据里，下次试穿可以直接点选，也可以删除。建议选脸部清晰、保留头顶与鞋履的单人全身原图。点选一格参考写真并确认照片用途后才会提交上传。试穿进度和成片都在「我的试穿」里查看。已保存到本机的成片可在同一浏览器继续查看和下载，清理站点数据会移除这些本地副本。在线生成需要可用的后台与生成服务，开发阶段管理员可评估生成成品。用户照片、私人试穿结果和运行凭据均使用私有存储。

人物与服装画面采用生成式创作，供穿搭灵感与视觉欣赏；细节可能变化，不代表真实尺码或合身度。

试穿可选「保留原姿态」或「变换姿态」。九宫格中央放入完整原图，外围展示同一套衣服的八种试穿姿态。中央原图随私有成片保存，后台预览会遮住这一格。
