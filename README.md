# 衣序 · Yixu Wardrobe

衣序是一间线上衣橱。通过九宫格写真探索搭配、单品和穿着细节。

[在线浏览](https://www.8882088.xyz/) · [English](README.en.md)

- **穿搭**。首页呈现最近发布的封面与更新。「全部穿搭」可按风格、季节、模特或地区筛选，也可按编号、名称或单品搜索。用「我有这件」从手头的西装外套、直筒裤、乐福鞋或风衣找穿法，也可按一到两种色系筛选写真色板。发布档案可按真实日期浏览各批穿搭。场景专题为通勤、周末散步和室内观展精选穿搭，每套附一句可照着搭的建议。打开详情可逐格查看九个镜头、复制公开单格链接、保存写真，或选择 2–3 套对比并切换到已确认的全身镜头。
- **模特与单品**。从模特页查看其穿搭，从单品页查看全貌、细节与原写真，也可在单品列表并排对比两件同类单品。根据有限参考补充的细节会标为设计推演。人物和服装画面采用生成式创作，供穿搭参考。
- **收藏与搭配清单**。穿搭和单品收藏分别保存在当前浏览器。从「我的收藏」打开搭配清单，可以为一次出门计划把穿搭和单品存到同一份本地清单。详情页可用左右方向键切换穿搭，按 Esc 关闭弹窗，按 `/` 搜索。
- **我的试穿**。在当前浏览器保存或删除试穿用照片与已取得的成片。确认照片用途后才可上传生成；可保留自拍原姿态，也可生成变换姿态的九宫格，中央是原图，外围是八个试穿姿态。后台评估预览会遮挡中央原图。

在线访问在服务端用离线 IP 库估算国家及中国省级归属，供管理员查看。归属地近似网络出口；服务端不保存原始 IP。试穿照片、结果与服务端记录按权限存取。

离线浏览时，完整复制构建生成的 `public/`，打开其中的 `index.html`。本地构建、代码入口和生产 SOP 见[开发说明](DEVELOPMENT.md)。
