## 慢慢挑 认真看

- **按风格与季节逛**：轻雅日常、都市层次、复古学院、机能街头、新中式等风格，配合春秋、夏季、冬季或四季筛选。
- **发现新内容**：按模特、地区或最新一组筛选，也可以按最新发布排序。历史图片未核对模特归属时，不会强行归给某位新模特。
- **找到心中那一套**：搜索名称、编号、单品、材质或情绪，试试“丝绒”“百褶裙”“惊喜”。
- **走近一个画面**：打开搭配，查看生动九宫格；选择 01—09，细看其中一个瞬间，再读单品与搭配思路。
- **留住喜欢的**：点心形收藏，把 2—3 套加入对比，或点击“保存图片”。旧编号与收藏继续对应原来的搭配。

键盘也能帮忙：`/` 搜索，`←` `→` 切换详情中的搭配，`Esc` 关闭弹窗。

公开界面只展示“生动”版。历史“造型”图片和资料保留在项目归档中，不再放进公开构建与浏览入口。

## 开始浏览

打开[衣序在线衣橱](https://www.8882088.xyz/)，即可浏览、筛选和收藏。仓库源码更新与线上部署分别进行，新功能是否已上线以实际部署为准。

前端通过资源接口读取更新。CDN 未配置或同步未完成时，使用项目中的 WebP 图片；同步验证成功后优先使用 CDN，加载失败时回退到项目图片。

离线浏览请使用构建后的 `public/` 文件夹，完整复制后打开其中的 `index.html`。无需安装浏览器插件或注册账号；请保留文件结构。生成离线包的方法见[开发说明](DEVELOPMENT.md)。源码根目录的 `index.html` 仍可直接打开，展示冻结的初始衣橱快照。

历史 200 张写真已转为原尺寸 WebP，图片合计 48,176,224 字节（约 48.18 MB）；公开构建按内容清单只打包可展示图片，不再包含历史造型图片。另有一张[女模特五视角基础体](assets/model-bases/female-01.webp)，用于系统模特 01 的后续穿搭创作。
