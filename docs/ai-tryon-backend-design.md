# 衣序：AI 试穿与第一方统计实施说明

- 更新日期：2026-11-11。
- 当前状态：依据用户访谈进入开发；代码、测试及部署分别验收，不把设计或 CI 当作上线证明。
- 主站：`https://www.8882088.xyz/`；管理入口：`https://admin.8882088.xyz/`，均使用 DNS-only 直连。
- 本文取代此前设计中的费用预算、生成配额、成品到期、LAN-only 管理及其他尚未确认的问卷建议。历史版本保留在 Git。

## 1. 已明确的产品规则

1. 不开发公众账号。打开页面自动签发浏览凭证并保存在浏览器安全 Cookie，同一有效凭证复用；所有任务、结果、下载、删除都校验所有者。
2. 当前镜头提供试穿入口，支持拍照与相册，定位为照片风格的穿搭效果，不承诺真实尺码或精准合身度。
3. 首次试穿弹出信息披露并主动确认。说明外部图像处理、开发阶段管理员可评估生成成品、自拍保存范围和成品滚动淘汰；自动浏览凭证不是照片处理同意。
4. 自拍原文件与归一化输入最多保存一小时。管理员不得查看或下载原图；不创建原图管理相册。
5. 生成结果统一 WebP，全站按完成顺序滚动保留最近 1,000 张。**没有成品时间到期规则，也不是累计只允许生成 1,000 次。**
6. 公网管理站首次初始化自动创建强随机管理员凭证，仅通过服务器私密文件交付，普通重启不重置；管理员可以查看生成成品和评估质量。
7. 排队信息持久化，不能因为刷新或断线丢失。执行状态必须真实，不能用虚构百分比或假结果掩饰错误。
8. **本项目不承担 OpenAI 费用、额度或调用频率治理。** 不做日/月预算、费用预留、用户/IP/全站生成次数限制、OpenAI 调用限速、验证码或试用码，也不把这些变成调用前置条件。
9. 其他问卷建议不预先写成固定业务规则：不设三条队列、五分钟等待、成品二十四小时、一年访客凭证等默认门槛。运行参数集中配置，参数语义明确。

上传文件校验、服务器资源背压、必要的网络错误处理、登录鉴权以及避免同一请求被重复调度属于系统正确性，不是重新包装的生成配额。未配置实际可用的图像服务时必须明确显示不可用，不能在生产用测试图片冒充生成成功。

## 2. 基础与模块

现有网站保持 100 套服装、两套写真、200 张九宫格 WebP、本地收藏、筛选、对比和精确备案号。原有静态资源必须保持哈希一致。

```text
主站浏览器 → Nginx → 公开衣柜 + 同源 API
                         ├── 浏览凭证 / 首次披露
                         ├── 持久任务 / SQLite / 第一方统计
                         └── 单图像 Worker
                              ├── 归一化与本地人像检测
                              ├── 当前镜头单格参考 + 穿搭文字
                              ├── localhost 专用代理 → 外部图像编辑
                              └── 验证、标识及私有 WebP 发布

管理子域名 → Nginx → 管理登录 / 统计 / 队列 / 成品评估 / 服务配置
```

- 后台采用 Python、FastAPI、SQLite；一个后台进程与一个 Worker 起步，按实测主机容量运行，不引入本地生成模型或无关基础设施。
- SQLite 保存真实队列；不预设三条等待上限。持续接收能力受实际磁盘、解析安全和进程资源约束，资源不足应如实报错，不伪装成已经接单。
- 应用仅监听 loopback，公开入口由 Nginx 按 `www` 与 `admin` 隔离。主站不转发管理 API，管理员会话和匿名访客凭证不混用。
- 生图使用直接图片编辑接口，不为了本功能建立长期保留的聊天或公开图床。

## 3. 浏览凭证、披露与前端

### 自动凭证

页面加载调用 `GET /api/bootstrap`，服务器签发或复用高熵、主机限定的匿名凭证。采用 `Secure`、`HttpOnly`、合适的 SameSite 和根路径，不设置共享父域 Domain，不把令牌放入 URL、localStorage、分析事件或日志。[S3]

不硬编码问卷里的一年寿命；是否设置浏览器持久期限集中配置。浏览器自身的 Cookie 生命周期和清理行为仍存在，不能宣传成永久身份。关闭弹窗不重新签发，暂时网络错误不清除现有凭证；用户清 Cookie、换浏览器或设备后不能恢复旧身份，首次披露说明这一点。

### 首次试穿

- 服装、写真版本和单格镜头在提交时冻结，用户浏览切换不能改写已接收任务。
- 首次试穿展示版本化披露，同意后才上传；后续相同版本不反复要求。处理范围变化时明确更新披露。
- 两个独立文件入口分别用于现拍和相册；相机不可用时仍可选文件。本地预览使用可释放的 Blob URL，不把照片/base64持久化到浏览器。
- 九宫格总览不是单场景。用户需确定其中一格，后台再按受控 catalog 裁切。
- 页面展示排队位置、真实状态、错误原因和结果下载；重新打开通过凭证查询已有任务，不靠只存前端的等待动画。
- `file://` 和旧纯静态托管仍能浏览衣柜；无同源后台时明确不提供试穿，不静默跨站上传。

## 4. 图像、外部服务与正确性

### 输入与场景参考

只接收受支持的真实单帧图像，检查字节、像素、帧数和解码错误；纠正方向、缩放并移除 GPS/设备等来源元数据。安全解析参数集中配置，不能信任前端 MIME、尺寸或“检测通过”的声明。

本地人像检测先于生成；无可用单人人像则给出重拍提示。检测只用于图像可用性，不做身份、人脸特征库、年龄或权属证明。YuNet 候选模型取自官方仓库，部署时固定实际文件与摘要并保留其许可证。[S4]

输入包括：

1. 用户自拍：唯一人物身份参考；
2. 当前九宫格中的选定单格：场景、姿态、光线；
3. 该套服装的受控单品、配色、材质和镜头文字；必要时另补同套服装的单格全身参考，而不是整张拼图。

公众请求不能指定任意 URL、文件路径、模型或自由提示词。模板要求单人、单场景、服装及场景匹配，参考模特不是目标人物。实际效果需授权小样验证，不把外部接口成功当作“像本人”的证明。

### OpenAI 配置而非治理

运行时由管理员设置独立项目 Key、模型、接口地址和专用代理；密钥只保存在私有配置，不回显给浏览器。模型能力和参数以实际官方接口及该账户权限为准；不虚构当前账户已获授权，不复用助手或其他应用凭据。[S1]

**不实现费用预算、扣费预留、生成次数或调用频率限制。** 记录必要的任务状态和提供方返回信息以诊断实际调用，不从用量统计推导一个隐藏的停机规则。上游拒绝、账号权限、网络或格式错误按真实错误处理。

每次任务产生一张目标成品，输出规格可配置；这是请求内容，不是费用治理。实际服务未配置则返回明确的不可用状态，不能接受注定无法处理的自拍或返回假图。

### 防重复调度

幂等键绑定浏览凭证、服装/镜头和接受的照片；重复点击或网络重试返回已有任务，不重复发起外部生成。使用持久状态记录可能已发送的边界；发出后超时、崩溃或结果不明转 `unknown`，不自动回队列。这仅保证本应用不主动重放，不宣称提供方计费 exactly-once。[S2]

已取得输出但本地处理失败时，只恢复本地处理，不重新生成。尚未发出的队列任务可恢复；其输入若已到一小时上限，删除输入并明确要求重新提供照片，不静默丢失排队记录或继续使用过期副本。

## 5. 文件与任务生命周期

### 自拍

一小时按服务器接收上传时刻计算，不能等生成完成后再多留一小时；成功、失败、取消、崩溃及排队均受同一上限约束。原始文件、归一化文件、框架/Nginx临时副本都纳入清理。启动及周期扫描作为异常兜底，禁止日志、备份或公开路径留下副本。

用户没有要求原图相册；**不存在管理员原图查看/下载接口**。管理员看到的只有生成成品及公开的服装/场景参考。

### 成品

- 私有目录保存单份 WebP；用户凭所有权、管理员凭独立管理权限读取。
- 无时间到期；超过 1,000 张按完成顺序删除最旧成品，后台任务状态同步更新。缩略预览复用同一文件，不保存隐蔽的长期 PNG/JPEG/base64副本。
- 最终文件应包含适用的可见 AI 合成标识和来源元数据；去掉输入 GPS 不等于去掉输出的生成属性。重新编码后验证文件与标识。[S5]
- 数据库与文件不是一个原子事务。以持久发布/删除意图、同文件系统暂存、fsync、原子改名和重启对账完成恢复；满额先撤权并删除旧成品，再发布新成品。清理失败不能靠无限堆文件掩盖。

### 排队

队列、任务输入引用、所有者、冻结场景、阶段和错误持久化。关闭页面不删除后台记录；浏览器刷新查询同一任务。没有问卷里的三条上限或五分钟自动失效；输入一小时上限仍必须执行。并发与资源参数独立配置，不因队列数量而谎报成功。

## 6. API 与管理员

### 公众 API

- `GET /api/bootstrap`：自动凭证、CSRF、披露版本和服务状态。
- `POST /api/disclosure/accept`：确认当前披露版本。
- `POST /api/tryons`：上传自拍并冻结 LOOK/版本/镜头，返回持久任务。
- `GET /api/tryons`、`GET /api/tryons/{id}`：恢复本凭证任务与排队信息。
- `GET /api/tryons/{id}/image`、`/download`：所有者的私有成品。
- `DELETE /api/tryons/{id}`：取消或删除本人的任务/成品。
- `POST /api/events`：最小化、白名单第一方统计。

所有照片、状态和删除均做服务器所有权校验，随机 ID 本身不是授权；写操作执行同源/CSRF校验。技术资源不足、输入无效、服务未配置与提供方失败分别报告，不泄露私有路径、Cookie、Key 或原始上游响应。

### 管理员

`admin.8882088.xyz` 有单独的 HTTPS 虚拟主机及匹配证书，既有 www 证书不会自动覆盖它。管理 API 不在公众主站提供；匿名浏览凭证无法提升为管理员。

首次初始化自动生成管理员账号及强随机密码，密码哈希存储；初始凭据只写到服务器私密交付文件（目录0700、文件0600），不在启动日志、公开文档、前端或普通聊天中展示。重启/升级不覆盖管理员。初始化并发和中断必须可恢复；密码轮换、退出撤销旧会话。[S6]

管理功能包括真实访问/任务统计、持久队列、生成成品预览、质量备注/可选标记、删除和图像服务配置。质量记录不作为公众生图门槛。管理员不得查看上传自拍。

## 7. 第一方统计与披露

统计访问、服装/镜头偏好、试穿入口、任务阶段、成功/失败、下载请求和成品容量。生成成功等数据以服务器记录为准，不能相信前端事件冒充成功。下载请求或 HTTP 传输不等于确认用户已保存到设备。

不接入第三方跟踪脚本，不记录照片、base64、凭证、完整 URL/query、完整来源地址或原文件名。不用访问统计构造隐蔽的 IP/用户配额。必要的任务诊断与可选浏览分析分开，明确实际采集范围。

开发期管理成品访问从首次披露起就明说，不能等系统稳定后才告知。完整法律文案可以继续完善；但照片处理、外部提供方、管理员可见范围、站内删除边界和用户授权不能隐瞒。适用的地区资格、外部保留、跨境与合成内容义务须在真实服务开放前核实；传输代理不是绕过提供方政策的授权。[S1][S5]

测试在 HTTP、图像处理/提供方适配器、公开 UI 行为和文件发布这些已设计的接口进行：先保留真实 RED，再最小实现到 GREEN。测试替身只证明合同和恢复，不冒充真实 OpenAI 效果。

必测：自动凭证复用、首次披露、跨凭证拒绝访问、管理/公众隔离、首次管理员不重置、管理员无原图接口、真实格式/人像拒绝先于生成、九宫格正确裁切、重试幂等、未知调用不重放、刷新/重启恢复队列、原图一小时清理、1001成品仅留最新1000、磁盘/删除失败对账、私有配置密钥不回显，以及原有衣柜交互和200图哈希不变。

真实检测器、浏览器手机布局、公网TLS、自动续期、新代理仅loopback及旧服务未被影响分别验证。未获项目Key或实际模型权限时，报告真实生成未完成，不拿测试图片交付为线上成功。
