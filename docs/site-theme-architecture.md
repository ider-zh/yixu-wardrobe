# 全站布局 Module 与内容状态

衣序前台与同源 `/admin/` 使用同一个本地主题入口。Editorial 保留留白叙事；Studio 将首页照片置前、列表改为更少列的大图卡片、产品使用图库与信息侧栏、后台采用导航侧栏和主工作区。两者改变信息布局，使用同一套公开内容与业务状态。

## Interface 与 Seam

`site-theme.js` 提供 `window.YixuSiteTheme`。调用方只需以下小 Interface：

- `mount(container)` 挂载同一种可键盘操作的布局菜单，不重复创建。
- `choose('editorial' | 'studio' | null)` 修改浏览器偏好；`null`（菜单“编辑推荐”）移除显式选择。
- `preference()` 返回显式布局或 `null`，不把初始 Editorial 当成用户选择。
- `resolve(fallback, urlPreview)` 只返回已登记的本地布局名。
- `subscribe(listener)` 监听偏好变更，返回取消监听函数。

Seam 位于公共页面、产品布局解析器和后台入口之间。偏好读写、未知值降级、存储失败、跨 tab 同步与菜单状态属于 Module 的 Implementation；调用方不直接读写布局存储。`create({document, storage, eventTarget})` 是可注入依赖的测试入口，生产页面使用单一实例。

浏览器键为 `yixu:site-theme:v1`，与穿搭收藏、单品收藏、筛选和试穿状态分开。存储不可用时当前 tab 仍能切换，但不会声称刷新后已保存。`storage` 的删除及 `clear()` 回到推荐模式，同步不反写存储，避免通知循环。前台与 `/admin/` 同源时共用偏好；离线页面不依赖在线主题服务。

解析优先级为：**有效产品 URL 预览 > 全局显式偏好 > 产品 `presentation` > Editorial**。无效 URL 不抹掉已有偏好或内容推荐，不产生远程脚本、样式地址或 CSS。显式覆盖布局时采用目标 Adapter 的默认 preset；推荐模式保留产品已经登记的安全 preset。

## 两个真实 Adapter

Editorial 与 Studio 是同一 Interface 上的两个本地 Adapter。它们只安排现有节点与本地样式：

- 首页在文字/照片顺序之间切换；图库、模特、收藏和穿搭详情保持原编号、顺序与图片比例，由公共样式改变列数、图幅和信息卡片布局。
- 后台在横向章节与侧栏工作区之间切换。原 `nav` 和 `section.panel` 节点只在原鉴权 `#workspace` 内移动，绝不复制指标或照片、移出隐藏容器或修改其 `hidden`。
- 产品继续复用 `product-themes.js` 中两套结构 Adapter。主题通知只重排当前公开产品 Module，按资源 ID 保留选中图；收藏显示通过注入的 `isLiked(id)` 从应用 Set 实时读取，避免使用初始 view 的旧值；放大 dialog 在产品根节点之外，保留当前图、位置和键盘行为。
- 试穿只应用布局样式，不替换或关开 dialog，不重建 file input、Blob 预览、参考 radio、任务或等待骨架。

主题不调用路由刷新，不改 hash、筛选、收藏或试穿请求。普通页面的既有节点和监听器保留；后台退出/401 仍由原业务逻辑清理私有内容。Adapter 只有节点引用，不缓存私有字段，因此切回任何主题都不能恢复已清除的数据。

## 静态交付合同

`site-resources.json` 是前台和后台核心资源的唯一清单，内容只允许单层本地 `html/js/mjs/css/svg` 文件名；`catalog.js` 继续由内容构建生成。`scripts/site-resources.mjs` 校验清单、HTML 引用与实际文件，拒绝重复、路径逃逸、缺失资源，以及清单/资源/后台目录的符号链接。

Node 检查、构建与本地交付读取同一合同。开发服务器发布控制器也读取候选内同一清单：已有旧版本无清单时兼容原十四文件，新版本纳入两张主题资源，核验十六个核心文件。声明文件只能作为常规本地文件，不能通过链接把服务器私有内容带入公开包。控制器的 root 所有安装副本仍需按开发部署流程审阅更新，不从仓库自动自修改。

后台通过 `../site-theme.js` 与 `../site-theme.css` 加载公开根目录的共享文件，不增加 `/admin/` 静态白名单，不放宽 CSP。前台使用普通本地脚本，支持完整静态包直接 `file://` 打开；不存在主题 CDN 或未知配置下载路径。

## 验证

`qa/regression-site-theme.mjs` 从同一 Interface 测试两个 Adapter、有效预览优先级、推荐模式、存储故障、删除/清空同步与私有节点身份；临时夹具把声明脚本链接到目录外私有标记文件，实际合同及构建必须拒绝，原可用输出不变。

真实 Chromium 使用合成接口与照片，在 320、390、1440 像素下检查前后台布局、键盘菜单、各公开路由、当前产品图与放大、本地 File/Blob/radio、排队任务节点、跨 tab/同源偏好、刷新、离线页面、退出/401 清理和横向溢出。测试不会调用 AI 服务，也不读取真实访客或照片。原后台、内容、图库和发布回归仍单独运行；源码通过不等同于服务器已发布。
