# 男模穿搭制作 SOP

从[通用穿搭 SOP](external-agent-sop.md)进入。本篇补充 `male-01` 的身份参考、运动感镜头、表情验收与默认发布入口。 [模特登记](../content/models.json)

## 身份与体态

- 同时附入用户批准的原始多视角角色设计图和登记表 `reference.file` 指定的穿衣五视角 WebP。用原始图锁定脸型、发型、眼镜、肩背、腰胯、肌肉量与四肢围度，穿衣五视角图用于核对登记身份。参考图里的基础服由目标衣装替换。体形随布料和姿态自然呈现，肩宽、躯干厚度和腿部比例保持一致。
- 原始图从仓库外的私有交接取得，缺少原始图时先补齐参考。实际输入和哈希记入私有制作记录，公开 `model_reference_sha256` 仍填写登记 WebP 的哈希。
- 审图至少对照正面全身与侧面或三分之四全身。宽松衣装从垂坠和外轮廓核对身体比例。仅将本次造型明确采用的配饰登记到 `pieces`，按产品 SOP 完成关联。

## 运动感与表情

- 按场景、鞋履和地面安排动作幅度。展厅用稳步、转向、收步、驻足和起身表现身体控制。户外步道可用快走、跨低阶、放慢步幅和自然摆臂。每套另写动作顺序，安排前进、变化和停顿，保留足够的全身或中全身镜头来检查落脚与衣装。
- 让步幅、支撑脚、重心转移和手臂交替摆动体现运动感。肩背自然舒展，下巴保持自然高度，头、眼和正在看的目标对齐。写清每格的视线落点，例如行进路线、落脚位置、展品或同伴。
- 表情随动作与场景切换，例如看路时专注、停下时放松、见到同伴时自然平视或露齿笑。通过有情节的互动安排笑容和目光接触，避免重复套用挥手、眨眼、扶眼镜等表演性动作。剔除低头抬眼、头眼方向错开的侧瞟、刻意眯眼、撇嘴或单侧坏笑，以及耸肩缩颈、向镜头近距离前探的姿势。
- 验收时按实际画面记录步态、视线、表情、手部和衣物随动作的变化。全身格核对支撑脚和重心，近景格核对视线与表情。通用数量门槛仍适用于常规制作，露齿笑、大笑或互动需要有合适的剧情和视线对象。用户直接批准的指定替换样片可按原图交付，并如实记录实际画面。

## 当地活动与发布入口

- 从主办方、场馆或文旅的活动页核对点位、开放时段和可达空间，用独立近期来源支持当期选题。结合天气、步行与换层需求决定衣装。让具体场景推动九镜头，例如展开导览、推门入店或迎风扶住外套领口。重写动作与情绪，逐格执行通用验收门槛。
- 默认登记 `model_only: true`，用户可指定扩大浏览范围。从 `#/models/male-01` 核对写真、单品和详情链接，并确认首页、全站穿搭、搜索、收藏列表及全站单品索引的可见范围。
- 替换已发布的日更写真时，沿用原穿搭编号、批次和单品顺序，在原批次登记新的写真资源编号、路径和哈希。逐件按新成片选择有效镜头，并同时更新 `reference_asset_id` 和 `shot_index`。
