# 男模穿搭生产 SOP

日更统一从[外部 Agent 热点穿搭生产 SOP](external-agent-sop.md)进入。模特解析结果返回本篇时，读完再选题。按下文选用身份与体态参考，照片验收、单品图组、清单与发布执行通用 SOP。

## 身份与体态参考

- 正式生图实际附入用户批准的原始多视角角色设计图作为主参考，用正面、侧面和背面锁定脸型、发型、眼镜、肩背与腰胯比例、肌肉量及四肢围度。按衣装的松量和结构表现身体与布料的关系，避免随运动、着装或镜头角度增肌、缩肩或改变身材比例。
- 同时附入模特登记表 `reference.file` 指定的穿衣五视角 WebP，作为登记版本和身份的辅助核对。若穿衣图遮挡身体轮廓，以原始图核对体态。两张图里的基础服只用于参考，目标衣装按当次策划替换。
- 原始图通过仓库外的私有交接取得，实际输入和哈希记入私有制作记录。缺少原始图时先补齐私有交接再正式出片。公开清单的 `model_reference_sha256` 继续记录登记 WebP 的哈希。
- 审图时至少对照正面全身、侧面或三分之四全身，核对肩宽、躯干厚度、腰胯比例和腿部轮廓。宽松衣装用垂坠和外轮廓核对，遮住的肌肉只按参考保持比例。

## 选地点和当天活动

1. 按上海时区确认发布日期。实际搜索近期有公开信号的目的地、活动与男装穿搭灵感，写出三个候选。每个候选写明城市、具体点位、活动、适用时段与可核实的热度信号。
2. 打开官方场馆、主办方或当地文旅的具体活动页面，核对地点、活动日期、开放时段和可到达的空间。另找独立的近期报道、现场街拍或可核验的公开讨论，判断这个点位为何值得选。网页中的通用推荐不作为近期热度证据。记录链接、发布时间和检索时间。用户指定地点时先核实该地点的实际条件，按可核实的证据表述热度。
3. 用所选城市当天的正规天气来源核对高低温、降水和风力，并按活动时段判断室内外动线、步行距离和换层需求。优先选择地点、活动和天气能共同支持的方案。把实际预报与穿衣判断分别记进选题记录，清单沿用通用 SOP 的研究字段。

## 按场景决定衣装

从当天活动与天气反推层次、版型、面料观感和鞋包，结合已核验的当期穿搭信号。户外步行关注保暖、防风、摩擦和鞋履，室内观展关注自由活动和进门后的温差，雨天户外关注鞋底、裤脚和行走环境。场景允许时可以选休闲、运动、通勤或正式搭配，配色和轮廓随每套主题变化。

冻结服装的具体款式、件数、颜色、纹理、长度、叠穿次序和扣合状态。鞋包和配饰按实际设计写入 `pieces`。区分登记参考中的身份特征与搭配单品，只有确实属于本套穿搭设计的配饰才登记独立单品。九格执行同一套衣装。每次选题对照近期批次的地点、款式和配色，对重复的组合记下采用理由。

## 写当次九镜头微故事

先写清模特当天做什么、与观者是什么关系、情绪如何随行动发展，再为每格安排表情、动作、景别、鞋履与互动。用现场可见元素推动动作。展厅可以展开导览折页、循指示换展区、示意观者看某件作品。街区可以推门进店、拉椅落座或从室内走到街角。秋冬公园可以迎风扶住已扣合的外套领口、跨上台阶或俯身看路边叶片，让外层和裤腿随动作自然变化，并保持约定的叠穿状态。每套挑选适合现场的动态瞬间，跑步留给确实适合的运动场景。

用辨识度足够的神情交代情节变化。可从专注、惊喜、思索、会心露齿笑和张口大笑等不同状态安排反应，观者互动同时通过眼神、手势和身体朝向表达。对照近期脚本调整动作组合、景别、互动方式、展开顺序和收束，避免把上套脚本换地名重用。逐格以成片核对通用门槛，至少五种表情（含露齿笑与张口大笑）、六种动作、三格含完整鞋履的全身或中全身、五格与观者互动。

## 随写真交付单品和模特页

写真验收后，按[单品图组与产品页 SOP](product-agent-sop.md)按原序为每件 `pieces` 单品交付独立页面。使用成片中能看清相应结构的镜头作为穿着参考，核对 `look_id`、`piece_index`、写真修订和实际镜头。任务明确只做写真时，交付写真即可。

采用本 SOP 的新穿搭默认登记 `model_only: true`。从模特列表进入对应模特页，例如 `#/models/male-01`，核对当次穿搭的九格、产品链接和稳定详情地址。验证首页、最近更新、全站穿搭、搜索、收藏及全站单品索引的展示范围。用户明确扩大入口时按本次指定的范围交付。
