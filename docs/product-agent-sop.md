# 单品图组与产品页 SOP

先验收生动九宫格，再按 `pieces` 顺序为每件单品制作或复用图组。新穿搭默认与单品一起交付。补做已发布单品沿用原穿搭编号、批次与封面。 [穿搭制作 SOP](external-agent-sop.md#单品页随穿搭一并交付)

## 定位写真与批准设计

1. 锁定 `look_id`、从 1 开始的 `piece_index`、当前 `reference_asset_id`、写真路径和 SHA-256。打开该修订完整九宫格和实际可见的局部，选择能说明穿着比例或结构的 `shot_index`（1–9）。
2. 查找已有 `product_id`、主图、附图和关联。只在人工确认确为同一设计时复用已验收资产，同名款不自动合并。多个 agent 可按单品分配文件与资源 ID，由统一负责人合并清单。
3. 在私有制作记录区分原写真可见结构、已批准的单品设计和未知部位。用原写真约束可见服饰，批准母图锁定其余设计。缺少母图时先验收主图。未知背面、内里、包内结构、鞋底、耳针和耳堵优先省略。计划补充设计时披露推演范围。

## 按信息量规划图组

最终交付约竖版 `4:5` 的独立 WebP。主图全件入镜，保留适度留白和真实承托，以克制中性背景、柔和光线及自然阴影展示轮廓。画面保持干净，无人物、文字、品牌和水印。主图与完整角度单独生成。

| 图像角色 | 需要交代的信息 |
| --- | --- |
| 主图 | 完整轮廓、比例、颜色与可见结构。 |
| 全貌 `view` | 另一个有信息增量的完整角度，保留衣摆、袖口、鞋跟或肩带。 |
| 细节 `detail` | 单独取景说明领口、腰头、拼缝、垂坠、表面或其他已知结构。生成纹理仅供设计表达。 |
| 穿着参考 `appearances` | 复用原写真中的有效镜头，展示人与其他单品的比例关系。 |

附图按参考覆盖与信息增量决定数量，简单单品可只交主图。需要调整光线、背景或承托时，以批准母图为编辑对象并并排核对；新角度或近景同时参考批准母图和原写真，逐张检查色型与结构。裁切只按其来源标为主图局部或原写真穿着参考。真实品牌、材质成分、尺码、价格和货源须有独立依据。

## 双联切分与审图

- 同一单品的两张相关细节可生成左右等大双联。居中留贯穿全高的近白分隔，两边与主体保留安全距离。
- 切分前检查像素，确认中线附近连续、近白、低变化的分隔带，以及左右有效宽度与保留像素。把合图、检测阈值、白边坐标和裁切框留在私有记录。无法可靠识别、主体越界或安全裁切后像素不足时，改用独立镜头。
- 去除完整分隔带，逐张核对轮廓、比例、颜色、接缝、物理承托和 100% 像素下的边缘、纹理与压缩质量。图像保持原生尺寸，或做保留主体的安全裁切。色型漂移、伪造品牌、相邻画面串入、明显接缝错误或把未知工艺表述为事实的图退回修正。
- 打开最终单帧有损 WebP，记录路径、尺寸、字节数与 SHA-256。新修订使用新路径和资产 ID。批准参考、母本、完整提示词和过程记录留在仓库外。

## 登记与页面验收

- [content/products.json](../content/products.json) 按 [products.schema.json](../content/products.schema.json) 登记稳定 `product_id`，资源放在 `assets/products/`。完整主图用 `asset`，可选 `gallery` 最多八张附图。每项填写 `title`、`caption`、`asset`，`role` 为 `view` 或 `detail`，省略时按细节展示。
- 推演附图写 `design_study: true` 并在 `caption` 指出缺少参考的部位。主图含设计补充时写入产品描述或说明。每个 `appearances` 条目必须指向当前写真修订及有效镜头，每个穿搭的同一单品序号只登记一次。
- `copy` 可提供主题章节的纯文本标题。页面由全站主题渲染，内容交付可省略 `presentation`。主题与画廊实现见 [product-themes.js](../product-themes.js)、[product-page.js](../product-page.js) 和 [product-themes.css](../product-themes.css)。
- 运行穿搭 SOP 的[校验命令](external-agent-sop.md#5-验证和交付)。从穿搭逐件打开单品页面，检查桌面和手机的主图、附图、缩略图、放大、推演说明、原写真镜头预览、穿搭链接和收藏。核对快照与 API 内容版本，以及项目图与 CDN 的实际可用性。交付报告按原单品顺序列出新增、复用或省略的图、参考镜头、推演披露、图片元数据和验收结果。
